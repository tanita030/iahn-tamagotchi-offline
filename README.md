# IAHN Tamagotchi V46.1 — MODO LOCAL

Versión alternativa para jugar sin Firebase y sin consumir ninguna cuota de Firestore.

## Qué mantiene
- Personalidad de Iahn y las 28 caras.
- Toques, enfado y desaparición durante 5 segundos.
- Comidas y reacciones.
- Animaciones aleatorias.
- Estadísticas, cuidados y juegos.
- Habitación, gato, tienda y estrellas.
- Galería/memes guardados en este navegador.
- PWA instalable.
- Actividad local guardada en el navegador.

## Qué NO tiene
- No hay Firebase.
- No hay sincronización entre dispositivos.
- No hay usuarios conectados compartidos.
- El chat/actividad es local a este navegador.

## Para usarlo
Sube todos los archivos de este ZIP al nuevo repositorio de GitHub Pages. No necesitas crear ni configurar Firebase.
